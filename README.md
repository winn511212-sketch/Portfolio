# winnverse — Alisher's Portfolio (React + Vite + Tailwind CSS + Three.js)

Neonmorphism uslubi, maxsus kursor, 3D fon va kirish animatsiyasi.

## Ishga tushirish
Windows: `START.bat` ni ikki marta bosing (Node.js kerak: https://nodejs.org — LTS).

Yoki terminalda:
```bash
npm install
npm run dev
```
Production: `npm run build` (natija `dist/`). Render/Netlify: Build `npm run build`, Publish `dist`.
